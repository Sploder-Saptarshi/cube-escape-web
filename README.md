# Cube Escape Web

Ruffle-based web port of the Cube Escape Collection.

## Project Layout

- `original/` The untouched source files from the game (SWF, sounds, translations, promo XML, favicon).
- `patches/` ActionScript source files used to modify the main SWF.
- `build.sh` The build script: copies originals, patches the SWF, splits large assets, writes the manifest.
- `patch.sh` A smaller standalone script that only copies and patches the SWF (no splitting).
- `index.html` The page that loads Ruffle, streams the chunks, and boots the game.
- `sw.js` The service worker that serves `assets/sounds.swf` from cache.
- `assets/` Build output, generated by `build.sh` and ignored by git.
- `.github/workflows/deploy.yml` The CI workflow that builds and deploys to Cloudflare Pages.

## Requirements

- Bash (Linux or macOS)
- Python 3
- FFDec (the command line tool `ffdec` on your `PATH`)

The `assets/` directory is generated and committed to nothing; it is recreated by the build.

## Building Locally

```bash
# Make sure ffdec is on your PATH and Java 8+ is installed.
./build.sh
```

After a successful build, `assets/` contains:

- `CubeEscapeCollection.swf.part.000`, `.part.001`, ... the split chunks.
- `sounds.swf`, `cube_escape_translations.xml`, `promo_game.xml`, `favicon.png` copied from `original/`.
- `manifest.json` listing the chunk files, a content hash, and the total SWF size.

To try the site locally, serve the repository root:

```bash
python3 -m http.server
```

then open `http://localhost:8000`.
